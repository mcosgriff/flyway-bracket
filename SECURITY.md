# Security policy

## Reporting a vulnerability

Please report it privately through GitHub:
[Report a vulnerability](https://github.com/mcosgriff/flyway-bracket/security/advisories/new) (the
"Security" tab, then "Report a vulnerability"). Don't open a public issue for it.

Flyway Bracket is maintained by one person in their own time, so there is no fixed response time; a report
will be acknowledged as soon as it is read.

## What counts

For example:

- data leaving the phone that the app doesn't say it sends;
- a tracker, or a permission the app doesn't explain, in a build of the app;
- a way to see another player's location or sightings that they did not share;
- a way to change a league's results without logging the sightings.

## Supported versions

Nothing is released yet. Once there are releases, only the latest gets fixes.
